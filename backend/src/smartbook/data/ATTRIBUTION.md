The file is an unmodified copy of `en` at commit `5faf2ba42d7b1c0977169ec3611df25a3c08eb13`.
Smart Book ignores some of its entries that readers need in order to talk about real books
(`BOOK_TOPIC_WORDS` in `moderation.py`); the file itself is not changed.
